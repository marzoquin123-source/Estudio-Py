@ 1-1 | saludar | nombre
desc:
Crear una función que reciba un nombre (str) y retorne el saludo
"Hola, <nombre>!".
demo:
print(saludar("Ana"))
salida:
Hola, Ana!
test: "Ana" => "Hola, Ana!"
test: "Luis" => "Hola, Luis!"
test: "" => "Hola, !"
pista: Los textos (str) se pueden unir con el operador +.
pista: Une tres partes: el texto "Hola, ", la variable nombre y el texto "!".
codigo:
return "Hola, " + ___ + "___"
